На этой вкладке находится список всех аддонов модификации — как встроенных, так и созданных для интеграции со сторонними модификациями.

Для каждого аддона отображается его идентификатор пакета и текущий статус:

- **Активен** — аддон включён и работает.
- **Отключён** — аддон был вручную отключён с помощью кнопки.
- **Неактивен** — модификация, предназначенная для данного аддона, не установлена.
- **Доступен для скачивания** — аддон не входит в пакет Optimus; используйте кнопку «Скачать», чтобы его получить.

Аддоны установленных модификаций включаются автоматически, отдельно активировать их не требуется. Однако при необходимости любой аддон можно временно отключить (и включить обратно) одной кнопкой — эффект наступает сразу. Это может пригодиться, например, при диагностике проблем форума.

## Настройки аддонов

Если у аддона есть собственные настройки, рядом с ним отображается ссылка **Настройки**. Клик по ней раскрывает блок с опциями конкретного аддона прямо на этой же странице.

Эти опции больше не выводятся на общих страницах настроек модификации — каждый аддон хранит свои настройки в собственном блоке.

Разработчики аддонов могут добавить поддержку собственного блока настроек, реализовав интерфейс `HasSettingsInterface` — см. [Как создать собственный аддон](../../addons/new_addon).
