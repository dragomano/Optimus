When adding a new site to Google Search Console (or another similar service), you are usually asked to confirm your ownership of the website in one way or another.

Choose the option "via meta tag", specify this meta tag in the settings below, and voilà — the service will recognize you.

If the required tag is not initially in the list, you can add it.

Additionally, you are free to use this tab to add any other additional meta tags by specifying their name and value.

## Favicon
---

At the bottom of the tab, there is a field for the favicon code — the tags specifying the site icon, for example: `<link rel="icon" type="image/png" href="favicon.png" />`. This code is loaded at the top of the site pages, between the `<head></head>` tags.

You can use special icon generators (a link to one of them is provided in the hint above the field), or you can write the necessary tags yourself. After generating, upload the favicon files to the forum root and save the code from the generator site in the field.
