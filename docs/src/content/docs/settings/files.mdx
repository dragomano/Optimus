This tab combines the editors of two files located in the forum root: `robots.txt` and `.htaccess`. Be careful — errors when editing these files can harm indexing and forum operation.

## Manage robots.txt
---

The robots.txt editor consists of two columns. The left column contains recommended (but not mandatory) rules, while the right column allows you to directly edit the contents of `robots.txt`.

The rules generator may change its recommendations after the installation of certain mods (such as portals). You will need to reflect these changes in the right column.

You are free to ignore the generator's rules and write your own if you are familiar with the nuances.

## Manage .htaccess
---

Sometimes you need to quickly edit something in the `.htaccess` file, and accessing the hosting panel or using FTP may seem complicated or even too time-consuming for many.

For example, after removing the PrettyURLs modification, which makes changes to this file, the changes may remain and could lead to issues later on.

If the file does not exist but you need to create it, simply fill in the field and save the changes, and the file will be created. A backup copy (`.htaccess.backup`) is created automatically before each save.
